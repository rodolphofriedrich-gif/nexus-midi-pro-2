# Português (Brasil)

## Versões com suporte

As correções de segurança são priorizadas para a versão mais recente disponível na branch principal. Versões antigas podem não receber atualizações.

## Como relatar uma vulnerabilidade

**Não publique vulnerabilidades, credenciais, dados pessoais ou arquivos sensíveis em Issues ou Pull Requests públicos.**

1. Se a opção **Private vulnerability reporting** estiver disponível na aba **Security** deste repositório, utilize-a.
2. Caso contrário, entre em contato com o mantenedor por meio do perfil do GitHub: https://github.com/rodolphofriedrich-gif.
3. Inclua uma descrição do impacto, passos para reproduzir e versões afetadas. Não envie dados de usuários reais.

O mantenedor avaliará o relato e poderá solicitar informações adicionais. Não há prazo de resposta ou correção garantido.

## Escopo

Relate problemas que possam afetar a confidencialidade, integridade ou disponibilidade do aplicativo, incluindo exposição de dados, execução de código não autorizada, falhas de permissões ou dependências vulneráveis com impacto demonstrável.

# English

## Supported versions

Security fixes are prioritized for the latest version available on the default branch. Older versions may not receive updates.

## Reporting a vulnerability

**Do not disclose vulnerabilities, credentials, personal data, or sensitive files in public Issues or Pull Requests.**

1. If **Private vulnerability reporting** is available in this repository's **Security** tab, use it.
2. Otherwise, contact the maintainer through the GitHub profile: https://github.com/rodolphofriedrich-gif.
3. Include the impact, reproduction steps, and affected versions. Do not submit real users' data.

The maintainer will review the report and may request additional information. No response or remediation timeframe is guaranteed.

## Scope

Report issues that may affect the application's confidentiality, integrity, or availability, including data exposure, unauthorized code execution, permission failures, or vulnerable dependencies with a demonstrable impact.
